# Programa Cosístico de Ventas

Este es un sistema ligero de gestión de productos e inventario. Cuenta con una API (Backend) construida en Node.js con Express y SQLite, y una interfaz de usuario (Frontend) desarrollada en HTML y JavaScript puro.

## 📋 Requisitos Previos

Antes de comenzar, instalar lo siguiente en tu computadora:

*   **Node.js:** Necesario para ejecutar el servidor y gestionar los paquetes.
*   **Visual Studio Code:** Con la extensión **Live Server** instalada para ejecutar el frontend (botón "Go Live").

---

## 🚀 Guía de Instalación y Uso

Para ejecutar el proyecto en tu entorno local:

### Instalar las dependencias
Ejecutar en la terminal el siguiente comando:
- npm install
  
### Correr el servidor
- npm run dev
